SkinMe(이하 "서비스")는 이용자의 개인정보를 중요하게 생각하며, 수집을 최소화합니다.
서비스는 광고·제품 판매·제3자 마케팅을 하지 않습니다.

## 1. 수집하는 정보

| 항목 | 수집 시점 | 보관 |
|---|---|---|
| 셀카 사진 | 촬영 시 | **저장하지 않음** - 분석 직후 기기·서버에서 즉시 삭제 |
| 피부 분석 결과(점수 등 수치 데이터) | 분석 완료 시 | 서버(익명 계정에 귀속)에 저장 |
| 등록한 제품명·측정 기록 | 이용자 입력 시 | 서버에 저장 |
| 익명 계정 식별자 | 앱 최초 실행 시 자동 생성 | 서버에 저장 (이름·이메일 등 신원정보 없음) |
| 구독·결제 상태 | 구독 시 | 결제 대행사(RevenueCat)를 통해 처리 |

- 서비스는 이름, 이메일, 전화번호, 성별, 생년월일 등 신원 정보를 수집하지 않습니다.
- 온보딩에서의 선택(관심사 등)은 기기 내에만 저장되며 서버로 전송되지 않습니다.

## 2. 사진의 처리 (중요)

촬영한 사진은 피부 분석을 위해 일시적으로만 사용되며, **분석이 끝나는 즉시 기기와 서버 양쪽에서
삭제됩니다. 사진 원본은 어디에도 저장되지 않습니다.** 저장되는 것은 분석으로 산출된 수치 결과뿐입니다.

## 3. 정보를 처리하는 위탁·제3자

| 제공받는 자 | 목적 | 제공 정보 |
|---|---|---|
| Anthropic (Claude API) | 사진의 피부 분석 | 분석용 이미지 (분석 후 미보관) |
| Supabase | 계정·분석 결과 저장 | 익명 계정 식별자, 분석 결과 |
| RevenueCat / [Google Play·App Store] | 구독 결제 처리 | 구매·구독 상태 |

## 4. 보유 기간 및 파기

- 사진: 분석 직후 즉시 파기 (보유하지 않음)
- 분석 결과·제품 기록: 이용자가 삭제하거나 서비스 이용을 중단할 때까지
- 이용자는 앱 내 **설정 > 기록 전체 삭제**로 언제든 모든 기록을 삭제할 수 있습니다.
